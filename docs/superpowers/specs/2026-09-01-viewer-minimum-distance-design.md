# ビューワー・2図形間最小距離計測 設計

## 1. 目的

プレビュー上で図形を2つクリックし、その2図形の最小距離を表示する。図面上の隙間や干渉をCADへ持ち込む前に確認できるようにする。

計測はブラウザ内の同期処理で完結し、外部へ送信しない。既存の通常表示、差分表示、パン、ズーム、DXF変換の動作は変更しない。

## 2. 対象範囲

### 2.1 選択

- 表示中の図形をクリックで選択する。選択の単位はパーサーが出力する図形1つとする。連続線は全体で1つの図形として扱う。
- モード切り替えを設けず、通常表示でも差分表示でも常にクリックで選択できる。
- 1つ目と2つ目を選択した時点で最小距離を算出して表示する。
- 同一ファイル内の2図形どうしも計測できる。

### 2.2 計測

- 2図形の実体どうしの最小距離を厳密に求める。線分は端点で区切られた有限の線分、円弧は掃引範囲に限定した弧として扱う。
- 交差または接触する2図形の距離は`0`とする。
- 距離の単位はmm固定とし、小数3桁で表示する。

### 2.3 対象外

- 文字図形の選択と計測
- 3図形以上の同時計測、計測結果の履歴と保存
- 角度、面積、周長、座標値の計測
- スナップ点（端点、中点、中心）の明示表示と点指定の計測
- 計測結果のDXFまたは画像への書き出し

## 3. 採用方式

計測とヒットテストは`src/viewer/measure.js`の純粋関数として実装し、メインスレッドで同期実行する。

1クリックあたりの処理は「表示中の全図形と1回ずつ点距離を計算する」`O(n)`、最小距離の計算は選択した2図形の要素数だけの`O(n·m)`であり、既存のHPGL解析より軽い。専用Workerは追加しない。

円弧は角度の掃引範囲を持つ弧として扱い、円は掃引360度の弧として同じ経路で計算する。円弧の掃引判定は既存の`src/viewer/geometry.js`と同じ規則（正の剰余と`1e-9`の許容誤差）を用いる。

## 4. モジュール構成

### 4.1 `src/viewer/measure.js`（新規）

計測に必要な純粋関数を提供する。入力を破壊せず、非有限値を検出した場合は既存モジュールと同じ方針で`TypeError`または`RangeError`を投げる。

公開関数は次の3つとする。

```js
pointToGeometryDistance(point, geometry) // -> number
pickGeometry(candidates, worldPoint, tolerance) // -> { index, candidate, distance } | null
minimumDistance(a, b) // -> { distance, pointA, pointB }
```

- `pointToGeometryDistance`は点と図形の最小距離を返す。`text`型を渡した場合は`Infinity`を返し、選択対象から外れるようにする。
- `pickGeometry`は`{ geometry, ... }`を要素とする候補配列を受け取り、`tolerance`以内で最も近い候補を返す。該当がなければ`null`を返す。距離が等しい候補が複数ある場合は配列の先頭に近い候補を返す。
- `minimumDistance`は2図形の最小距離と、その距離を与える各図形上の点を返す。距離が`0`の場合、`pointA`と`pointB`は同じ接触点または交点の1つとする。

### 4.2 幾何プリミティブ

`measure.js`の内部関数として次を持つ。すべて解析解で求め、数値探索は行わない。

- **点↔線分**: 線分への射影パラメータを`[0, 1]`へクランプした点までの距離。
- **点↔弧**: 中心からの距離を`d`、半径を`r`とする。中心から点への方向角が掃引範囲内なら`|d − r|`。範囲外なら弧の両端点までの距離の小さい方。点が中心と一致する場合は`r`を返す。
- **線分↔線分**: 交差する場合は`0`。交差しない場合は「各端点↔他方の線分」4通りの最小値。
- **線分↔弧**: 線分と円の交点を2次方程式で求め、掃引範囲内の交点があれば`0`。ない場合は次の候補の最小値。
  - 線分の各端点↔弧
  - 弧の各端点↔線分
  - 中心から線分への最近点`P`について、`P`が中心と異なり、その方向角が掃引範囲内なら`|‖P − 中心‖ − r|`
- **弧↔弧**: 2円の交点を求め、両方の掃引範囲内にある交点があれば`0`。ない場合は次の候補の最小値。
  - 各弧の端点↔他方の弧
  - 中心間距離が`0`でない場合、中心を結ぶ方向`u`上の4点`中心1 ± r1·u`と`中心2 ± r2·u`のうち、それぞれの方向角が自分の掃引範囲内にある点どうしの距離
  - 中心が一致する場合、2つの掃引範囲に重なりがあれば`|r1 − r2|`

上記の候補集合は、内部の停留点が中心を通る直線上に限られるという性質から、常に真の最小値を含む。内包する配置では一部の候補が真の最小値より大きい値を返すが、最小値を取るため結果は変わらない。

### 4.3 図形の展開

`line`と`polyline`は連続する頂点対の線分列へ、`circle`は掃引360度の弧へ、`arc`はそのまま弧へ展開する。展開した要素の総当たりで最小値と最接近点対を求める。`text`は展開せず、`minimumDistance`へ渡された場合は`TypeError`を投げる。

### 4.4 `src/viewer/canvas-renderer.js`

`renderViewer(canvas, groups, viewport, options)`の`options`へ`overlay`を追加する。

```js
overlay: {
  highlights: [geometry, ...],
  segment: [pointA, pointB] | null,
}
```

- `overlay`が未指定の場合、描画結果は現行と同一とする。
- ハイライトは全グループの描画後に、線幅`3.5`、色`#111827`で選択図形を重ね描きする。
- `segment`は破線で結び、両端へ半径`3.5 CSS px`の丸マーカーを描く。
- 2点が同一座標の場合は破線を省略し、マーカーのみを描く。
- 破線と丸マーカーの大きさは拡大率に依存しない画面上の固定値とする。

### 4.5 `src/app.js`

選択状態と操作を追加する。

- `state.selection`に選択した候補を最大2件保持する。
- ポインター操作からクリックを判定し、ヒットテストと計測を実行する。
- 計測結果の行を描画し、`overlay`を`renderViewer`へ渡す。
- 選択を解除すべき状態変化で`state.selection`を空にする。

## 5. 画面設計

### 5.1 操作

- `pointerdown`の位置を記録し、`pointerup`までの移動量が`4 CSS px`未満の場合だけクリックとみなす。既存のドラッグによるパンと共存させる。
- 許容半径は`8 CSS px`とし、`viewport.scale`で図面座標へ換算して`pickGeometry`へ渡す。
- 候補は現在Canvasへ描画している図形に限る。通常表示では表示チェックがオンのファイルの図形、差分表示では表示中の3グループの図形を対象とする。文字図形は候補から除く。
- 選択の遷移は次のとおりとする。
  - 未選択でヒット: 1つ目として選択する。
  - 1つ選択済みで別の図形にヒット: 2つ目として選択し、最小距離を表示する。
  - 1つ選択済みで同じ図形にヒット: その選択を解除する。
  - 2つ選択済みでヒット: いままでの選択を破棄し、その図形を新しい1つ目として選択する。
  - 何もヒットしない位置のクリック: 選択をすべて解除する。
- Canvas上でのEscキー押下で選択をすべて解除する。Canvasは`tabindex="0"`を持ち、キーボードでフォーカスできるようにする。
- 次の変化で選択をすべて解除する。
  - プレビュー解析の開始、完了、失敗
  - ファイルの表示チェック切り替え
  - 通常表示と差分表示の切り替え、比較対象A/Bの変更

### 5.2 計測結果の表示

プレビューパネルの状態行の下へ計測結果の行（`data-testid="viewer-measure"`）を配置し、`aria-live="polite"`を設定する。表示文言は次のとおりとする。

| 状態 | 表示 |
|---|---|
| 未選択 | `図形をクリックすると2つの図形の最小距離を表示します。` |
| 1つ選択 | `1つ目を選択しました（file1.hpgl の線分）。もう1つクリックしてください。` |
| 2つ選択 | `最小距離 12.345 mm ／ A: file1.hpgl の線分 ／ B: file2.hpgl の円` |
| 2つ選択かつ距離0 | `最小距離 0.000 mm（接触または交差） ／ A: … ／ B: …` |

- 図形種別の呼称は`線分`、`連続線`、`円`、`円弧`とする。
- 距離は`0.001 mm`単位へ丸めた小数3桁で表示する。
- 差分表示中の図形名は`Aのみ（file1.hpgl）の線分`のように、差分の分類とファイル名を併記する。共通図形は`共通（file1.hpgl と file2.hpgl）の線分`とする。

### 5.3 スタイル

- 計測結果の行は既存の`.viewer-status`と同じ字送りを用い、値を強調するための太字を1か所だけ使う。
- Canvasには選択可能であることを示すため、パン中以外は`cursor: crosshair`を設定する。

## 6. 状態とエラー処理

- 図形が0件、またはプレビューが失敗している場合、クリックは選択を発生させず未選択の文言を保つ。
- `minimumDistance`が例外を投げた場合は選択を解除し、計測結果の行へ失敗を示す文言を表示する。DXF変換とプレビュー表示は継続する。
- 計測は`state.previewFiles`の図形配列を読むだけで、内容を変更しない。
- アプリ破棄時、追加したリスナーは既存の`listen`経由で解放される。

## 7. アクセシビリティ

- 計測結果はCanvasの外のテキストとして提供し、`aria-live="polite"`で読み上げる。
- 選択は色だけでなく線幅の変化でも示す。
- Canvasはフォーカス可能とし、Escキーで選択解除できるようにする。
- 既存のモード切り替え、表示チェック、全体表示ボタンのキーボード操作は変更しない。

## 8. テスト方針

### 8.1 計測（`tests/viewer/measure.test.js`）

- 点↔線分: 垂線が内側に落ちる場合と端点側へクランプされる場合
- 線分↔線分: 平行、交差して0、端点どうしが最接近、T字配置
- 線分↔円: 外側、線分が円の内側、線分が円周と交差して0
- 線分↔円弧: 交点が掃引範囲外のため0にならない配置、弧の端点が最接近になる配置
- 円↔円: 離れた配置、内包、同心で`|r1 − r2|`、外接して0
- 円弧↔円弧: 掃引範囲が重なる同心、交点が片方の範囲外、端点どうしが最接近
- 連続線を含むペアで、最接近が中間セグメントにある場合
- 最接近点対が各図形上にあり、その2点間距離が返り値の距離に一致すること
- 文字図形を渡した場合の`pointToGeometryDistance`が`Infinity`、`minimumDistance`が例外
- 非有限値や不正な図形での例外
- `pickGeometry`の許容半径内・外、最近傍の選択、同距離時の先頭優先

### 8.2 描画（`tests/viewer/canvas-renderer.test.js`）

- `overlay`未指定時に現行と同じ描画命令になること
- ハイライトの線幅と色、選択図形の重ね描き
- 最接近点を結ぶ破線と両端マーカー
- 2点が同一座標のときに破線を描かないこと

### 8.3 UI（`tests/ui/app.test.js`）

- クリック2回で計測結果の行に距離が表示されること
- しきい値を超える移動を伴うポインター操作では選択されないこと
- 何もない位置のクリックとEscキーで選択が解除されること
- 同じ図形の再クリックで選択が解除されること
- 3回目のクリックで新しい1つ目として選択し直すこと
- 表示チェックがオフのファイルの図形が選択されないこと
- 表示モード切り替え、比較対象変更、プレビュー再実行で選択が解除されること
- 文字図形しかない位置のクリックで選択されないこと

### 8.4 全体検証

- `npm.cmd test`
- `npm.cmd run build`
- `git diff --check`
- 最新のEdgeまたはChromeで、`reference`内の代表HPGLを用い、線分どうし・線分と円弧・連続線どうしの計測結果と最短線の描画を目視確認

## 9. 完了条件

- 通常表示と差分表示のどちらでも、図形を2つクリックして最小距離をmm単位で表示できる。
- 線分、連続線、円、円弧のすべての組み合わせで、解析解による最小距離と最接近点対を得られる。
- 交差または接触する2図形で`0`を表示する。
- 選択図形のハイライトと最接近点を結ぶ破線をCanvasへ描画する。
- 既存のパン、ズーム、全体表示、差分表示、DXF変換の動作を変更しない。
- 実行時依存、CDN、外部通信を追加しない。
- 自動テスト、ビルド、目視確認を完了する。
