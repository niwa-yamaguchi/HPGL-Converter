# HPGL／Gerber／Excellon → DXF Converter

複数のHPGL／Gerber／Excellonファイルを、ファイルごとのレイヤーを持つ1つのDXFへ変換する静的Webアプリです。すべての処理がブラウザー内で完結し、入力ファイルを外部APIへ送信しません。

## 主な特徴

- 通常のHPGL／Gerber／ExcellonファイルとZIPアーカイブを入力可能
- 複数ファイルをまとめて1つのDXFへ変換
- ZIP内のサブフォルダを再帰検索し、対応するHPGLファイルだけを追加
- 入力ファイルごとにDXFレイヤーを作成
- Gerberの描画線は通常モードで輪郭、チェックボックス「描画線を幅なしで出力」で中心線として出力
- HPGLのペン設定は無視し、DXF図形をByLayerで出力（色・線種・線幅はCAD側のレイヤープロパティで制御）
- HPGLは40単位を1 mmとして変換し、基板データはファイルが指定した単位を使う
- エラーのある入力をスキップし、変換できた図形を出力
- 最初に追加できた元ファイル名をDXFの既定名として一度だけ自動設定
- 変換完了時にDXFを自動ダウンロードし、結果欄から再ダウンロードも可能
- プレビュー上で図形を2つクリックすると、その2図形の最小距離をmm単位で表示

## 対応ファイル

HPGLは `.hpgl`、`.hpg`、`.hgl`、`.plt`、`.plt1`〜`.plt99`、`.pltl`、`.pltl1`〜`.pltl99`、`.h01`〜`.h99` に対応しています。

Gerberは `.gbr`、`.ger`、`.pho`、`.art`、`.gtl`、`.gbl`、`.gts`、`.gbs`、`.gto`、`.gbo`、`.gtp`、`.gbp`、`.gm1`、`.g1`〜`.g99`、`.g01`〜`.g09` に対応しています。

Excellonは `.drl`、`.xnc`、`.dr1`〜`.dr99`、`.dr01`〜`.dr09` に対応しています。

補助リストはファイル名末尾が `X-GBLIST.txt` のGerber一覧と、`DRLIST.txt` / `DRLIST_M.txt` のドリル一覧です。補助リスト自体はDXFレイヤーにはせず、同梱したGerberのレイヤー名と、ヘッダーなしドリルの単位・座標桁・工具径に使います。

単位や座標形式を一意に決められないドリルは変換をスキップします。工具径が不明な穴は 1.0 mm の十字で出力し、レイヤー名へ未知工具を付けます。

`.zip` は次の上限で展開します。

- ZIP本体: 50 MiB以下
- 対応するHPGLファイル: 100件以下
- 展開後の1ファイル: 20 MiB以下
- 展開後の対応ファイル合計: 100 MiB以下

ZIP内のサブフォルダも再帰的に検索します。対応していないファイル、入れ子のZIP、ディレクトリ項目、安全でないパスは追加せず、種類別の件数を画面に表示します。

## 使い方

1. ZIPまたはHPGL／Gerber／Excellonファイルを選択するか、画面へドラッグ＆ドロップします。補助リストがある場合は製造ファイルと一緒に追加してください。
2. プレビューで図形をクリックすると1つ目として選択され、もう1つクリックすると2図形の最小距離を表示します。Escキーまたは図形のない場所のクリックで選択を解除できます。
3. 描画線を中心線で出したい場合は「描画線を幅なしで出力」を選びます。通常は輪郭、オンにするとD01が中心線になり、パッドと領域の外形は残ります。プレビューとダウンロードDXFは同じモードです。
4. 最初に追加できた元ファイル名からDXFの既定名が一度だけ自動設定されます。たとえば `drawings.zip` なら `drawings.dxf` になります。必要に応じて出力ファイル名を変更できます。その後ファイルを追加しても、既定名や変更した名前は自動変更されません。
5. 「DXFに変換」を押します。
6. 変換完了時に生成されたDXFの自動ダウンロードが始まります。
7. 変換結果を確認できます。自動ダウンロードを開始できなかった場合や、もう一度取得したい場合は、結果欄のボタンから再ダウンロードできます。

## ローカル開発

Node.js 22.12以降を使用してください。

```bash
npm ci
npm run dev
```

```bash
npm test
npm run build
```

実基板フォルダーがある場合は、通常モードと線幅なしモードのDXFを次で生成できます。出力は `tmp/board-reference-dxf` です。

```bash
npm run generate:board-reference-dxf
```

ビルド結果は `dist` に生成されます。

## Cloudflare Pages

GitHubリポジトリをCloudflare Pagesへ接続し、次の値を設定します。

| 設定 | 値 |
|---|---|
| Production branch | `main` |
| Framework preset | `None` |
| Build command | `npm run build` |
| Build output directory | `dist` |

環境変数、Functions、外部APIは使用しません。
